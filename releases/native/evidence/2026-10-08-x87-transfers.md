## Integer stores as one physical expression

FIST16/32, FISTP16/32/64 and FISTTP16/32/64 share one descriptor and pure SSA.
Inputs are raw extended fields, CW and empty predicate. Outputs are the signed
word, exception/C1/SF word, and store/pop suppression. For significand s and
effective exponent e (zero exponent uses 1), magnitude is s*2^(e-16446).
Guarded shifts recover integral/fractional parts; distances beyond64 preserve
only nonzero/below-half. RC applies nearest-even or sign-directed increment;
FISTTP fixes truncation. Range is [-2^(w-1),2^(w-1)-1], with increment carry
checked independently. NaN/infinity/unsupported/empty/range failure selects
the integer indefinite, invalid takes precedence over precision. PC is irrelevant.

Measured plan maximum: **70 abstract nodes/span25/17,936 arena bytes**,
not a minimal native instruction certificate. Independent official SoftFloat
checks **7,424 canonical masked** rows. Full raw hardware/SSA and actual C-MMU
execution compare **24,576** rows: 384 groups, eight encodings, all PC/RC,
masked/IE/PE contexts, sign/range/halfway/subnormal/unsupported/empty inputs.
There are 6,400 pending unmasked exceptions; 2,992 preserve original memory.

Unmasked invalid suppresses BOTH store and pop. Unmasked precision still
stores the rounded integer and pops while latching deferred #MF. Status and
write suppression are distinct predicates, not one combined exception branch.

An independent actual-x86 reference-build VM signal-frame oracle confirms
fault order in **64** cases: 16 write-protection #PF, 16 protected-page
non-faults with unmasked invalid, and their writable counterparts. Those same
records match the C VM's full expected FPU/CPU/memory and #PF/error outputs.
GPR/RF invariance here is architectural, not every physical host GPR captured.
Faulting stores keep the entire FPU image unchanged. Masked invalid and
precision must preflight and can fault; unmasked invalid does NOT even translate
or preflight the destination. Its computed EA only records the required FPU DP.

Thus no destination load, dummy write or empty write reservation is retained.
The existing write_begin/word/end C owner is called only for an actual store;
CPU/FPU/pop publication follows successful completion. Source retirement can
return STALE after a write invalidates admission; this is checked as one
completed instruction, never replayed or treated as a missing-block fallback.
Constructors: **64** prefix/width/pop/truncation forms, **768** malformed laws,
unchanged output/capacity failures. Additional C #NM/#MF-before-access and
readonly/cross-page/absent-page models pass **1,536** faults.

## Shared loads, not a second FPU engine

FLD32/64 uses the existing exact raw IEEE -> extended expression. FILD16/32/64
and these loads now share one push/exception/tag publisher. Signaling NaN
quiets only when masked invalid permits publication; stack overflow chooses
the indefinite with IE/SF/C1. Unmasked invalid suppresses push. Unmasked
denormal load still publishes the exact normalized value and pushes, while
latching deferred #MF. PC/RC do not round the exact widening conversion.
