# Raw x87 transfers through shared SSA — 2026-10-09

FCMOV's eight conditions/all eight source ranks, FCHS/FABS and the seven
constant loads now have one checked common frontend and pure transfer plan.
No host floating helper or runtime instruction switch is used. Source extent,
prefixes, operands/effects and encoded meaning must agree. FOP is now derived
from the decoded opcode/ModRM, not the first two source bytes (which were
wrong when a prefix was present).

The instruction families preserve raw 80-bit fields, including denormals,
NaNs and unsupported encodings. Conditional moves inspect both tags even on
a false condition. Empty values are constants; false conditions and alias
identities do not fetch latent numeric payload. Sign operations read/write
only the sign-exponent field unless a masked stack fault needs the indefinite
significand. Constants use fixed extended literals and RC-dependent rounding;
PC and precision flags do not participate. Neither a numeric lane array nor
a gathered FPU image is materialized.

Stack faults set IE/SF; overflow also sets C1. Unmasked cases preserve payload,
tags and TOP, set ES/B and retain the exception opcode, retiring the operation
before the next waiting instruction consumes the deferred exception. Masked
cases publish the indefinite value. FIP, tags, preserved condition bits and
full integer flags match independent observations.

584 constructor/prefix forms and 8,176 malformed controls pass. 37,376 pure
control combinations pass; compact graph maximum work/span is 18/6 (an upper
bound, not a global-minimum certificate). 37,376 independent physical Windows
FPU/full-tag/RFLAGS rows match 73 generated Wasm modules running on the actual
C MMU/table. Unobserved GPR invariance is architectural, not a measurement.
56,064 direct/C-table boundary models cover every form/prefix and EM/TS/MP,
NE, old masked/pending state: 42,048 #NM, 2,336 #MF, 2,336 legacy FERR waits,
9,344 retirements. Product/scoped postlink/positive ASan/UBSan gates pass;
