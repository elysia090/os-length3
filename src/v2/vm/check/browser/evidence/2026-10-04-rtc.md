## Canonical state and bounded transition

C retains an epoch-second coordinate, subsecond fraction, oscillator origin,
independently writable weekday phase, control/flag bytes, CMOS NVRAM and
the address/NMI-mask latch. The declared virtual board uses a 32768 Hz
oscillator, UTC Gregorian dates from 1970 through 9999, byte ports 70/71
and century32/37 alias. This range is a virtual-board contract, not a claim
that a particular RTC chip implements Gregorian centuries through 9999.
DST and alternative oscillator inputs are explicitly refused. NMI mask is
retained but NMI delivery and the unconnected SQW pin are not implemented.

For an admitted monotonic interval `d = new_ns - old_ns`, derive

```text
carry = floor((fraction + d mod 10^9) / 10^9)
seconds' = seconds + floor(d / 10^9) + carry
fraction' = (fraction + d mod 10^9) mod 10^9
ticks(t) = floor(t / 10^9)*32768 + floor((t mod 10^9)*32768 / 10^9)
PF' = PF OR (floor(ticks(new_ns-origin)/period) > floor(ticks(old_ns-origin)/period))
IRQF = ((C AND B AND 0x70) != 0)
```

Overflow/range and backwards-time checks precede mutation. Gregorian dates
use March-based 400-year eras, not a year/day loop. Alarm time is a product
of three fixed/wildcard digits; the earliest strictly later match is the
first feasible same-second-digit, later-minute, later-hour or next-day case.
One comparison with that deadline replaces iteration over elapsed seconds.

Normal running calendar reads derive only the requested field. Clock replies
do not re-materialize eight calendar fields; SET and divider controls pin a
bounded visible snapshot. Calendar writes substitute the incoming byte into
the *post-tick* projected calendar before validating it. A write spanning
00:00:59 -> 00:01:00 must not reuse the old minute. Weekday phase is separate
from date and advances across midnight; it is not silently recomputed after
an independent weekday write. Invalid alarm/calendar inputs are refused;
SET can temporarily hold an incomplete calendar, but clearing SET validates it.

The [RTC-compatible datasheet](https://www.analog.com/media/en/technical-documentation/data-sheets/DS12885-DS12C887A.pdf)
is the reference for encodings, read-only/status registers and interrupt
masking. C keeps PF independently of PIE, clears C on read and derives IRQ
from flags/enables. The board's SET-held calendar suppresses UF/AF, retains
the internal countdown and clears UIE. These declared device tests are not
universal silicon/timing equivalence.

## Ownership and precise execution

Supervisor-only `vm_rtc_start(port,generation,utc_seconds)` supplies UTC once
before first RTC I/O or clock advance. Invalid extent, stale generation,
duplicate/late seed and close-revoked records cannot initialize it. No clock
is implicitly read by the C device. The browser records its explicit host
UTC seed; this is not authenticated NTP or a trusted timestamp.

The shared I/O privilege/TSS-bitmap check precedes mutation, including for
unsupported widths. Index accesses are synchronous. Data accesses use the
existing sampled-clock barrier, with CMOS index included in its continuation
key. A reply binds generation, private record, RIP and non-reused ticket;
repeated identical replies are idempotent. No CPU/segment state retires on
wait/refusal/fault. Successful IN changes only the architecturally permitted
low parent, RIP/retirement and RF. Clock/device state is C-owned; JavaScript
supplies the event only. IRQ8 reaches C PIC state, not the CPU: interrupt
injection, APIC and STI shadow remain separate, incomplete work.

The compiled-provider test exposed another real red: an eligible PIC request
with IF=1 was silently ignored and the next IN retired. Fresh instruction
fetch now refuses that unowned delivery without acknowledging the PIC or
changing CPU state. A suspended instruction finishes its already-started
continuation; MOV-SS admits only its one inhibited successor. Masked requests
do not falsely stop execution, and mask/unmask does not consume the event.
These are fail-closed boundaries, not an implemented interrupt controller-to-
CPU delivery path or a substitute for the required STI/event work.
