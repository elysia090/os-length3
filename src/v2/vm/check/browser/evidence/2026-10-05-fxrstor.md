## Derivation from the required observations

The compiler, not a VM mnemonic callback, owns the FPU transformation. It
first checks CR0.EM/TS (#NM), then the complete aligned 512-byte read. Only
after successful access does it check reserved MXCSR bits (#GP). The supplied
MXCSR_MASK is information, not permission to enable reserved bits. Pending
unmasked x87/SIMD exceptions do not trap merely because state was restored.
These requirements follow [Intel SDM, FXRSTOR](https://www.intel.com/content/dam/www/public/us/en/documents/manuals/64-ia-32-architectures-software-developer-vol-2a-manual.pdf).

The necessary live payload is a projection of the authenticated read extent,
not another 512-byte image:

    physical_rank(i) = (TOP + i) & 7
    R[physical_rank(i)] = image.ST(i)
    tag[r] = empty, if !FTW[r]
             zero, if exponent == 0 && significand == 0
             special, if exponent in {0, 0x7fff} || integer_bit == 0
             valid, otherwise
    pending = (FSW & ~FCW) & 0x3f
    FSW' = (FSW & ~0x8080) | (pending ? 0x8080 : 0)

FCW/FOP reserved bits normalize rather than become live state. REX.W FIP
sign-extends the enumerated 48-bit linear-address width; non-REX pointers
use their 32-bit layout. FDP follows its specified width separately. The
FIP rule is also described in [Intel SDM corrections](https://cdrdv2-public.intel.com/835748/252046-sdm-change-document.pdf).
Unchanged native comparisons independently exposed both the FIP and ES/B
normalization omissions before they were corrected.

The generic `machine.read_extent(port, address, bytes, READ[|STACK|ALIGNED16])`
import publishes at most two `(offset,length)` fragments after full C-MMU
preflight. Its private port is 64 bytes, not a record image. Fault/wait leaves
those 16 descriptor bytes unchanged. No payload copy, gather, register-array
rotation, second translation or opcode import is introduced. Aligned fields
cannot straddle the page-aligned fragment boundary: generated code selects a
physical coordinate before its load, without touching the unused fragment.
All sixteen XMM lanes use direct v128 loads/stores, not 32 scalar payloads.

The view is borrowed only inside one synchronous serialized compiled call.
RAM, directory, context and residency cannot change between preflight and final
publication; no event/yield/provider call interleaves. It is not a persistent
capability, SMP lease or grant after that call. CPU/segments/port reservations
are disjoint. Paging A/D effects are not rolled back. Shared-worker concurrency
would require another proof; it is not inferred from these tests.

The fixed profile restores full XMM/MXCSR even with OSFXSR=0. Reserved/software
tail bytes are validated as part of the complete operand but are not loaded
into live state. Independent reference QEMU TCG observations require all 512
bytes accessible, preserve FPU state on the tested #PF/#GP and prioritize #PF
over invalid MXCSR when the second page is absent. That observer is not a
product execution route or universal physical-hardware proof.
