## Common lowering

SHL/SHR/SAR register operands at 8/16/32/64 bits use immediate/CL counts masked
to 31 or 63. Both source values are captured before CL/CH destination aliases.
Narrow parent writes and 32-bit zero-extension match actual native observations,
including zero-count 32-bit writes. Nonzero undefined AF/multi-bit OF and
undefined narrow logical-shift CF use deterministic zero representatives;
they are not claimed to match unspecified native flags.

For a flag bit b, let Kb be the last unconditional definition. A conditional
definition after Kb must survive, because count zero can preserve its incoming
value. Emit Kb and all later conditional definitions; when Kb is absent, the
incoming architectural bit is the root. Any earlier definition is killed on
every path by Kb. This establishes the exact frontier for the currently admitted
terminal-only flag consumers with two linear passes and twelve ranks. There is
no predecessor frame, source-instruction array or opcode callback. SETcc/ADC/
CMOV interior uses still require an extended dependency proof, not blind admission.

node data/oracle/check-wasm-dispatch.mjs VM.WASM temp/new-shifts
bash data/oracle/prepare-startup-cuts.sh BUNDLE.tar.zst \
  4438d58897f8795a69b77d46fcfd45259717c739f9a0419fd7c1541d089c77cc temp/new-startup
node data/oracle/check-wasm-startup.mjs VM.WASM COMPILER.WASM temp/new-startup
node data/oracle/prepare-browser-startup.mjs VM.WASM COMPILER.WASM temp/new-startup
node data/oracle/serve-browser.mjs --port=8080
# Open /src/v2/vm/check/browser/startup.html using ordinary browser control.

The script authenticates the archive before extraction and fixes these witness
coordinates to the shipped kernel digest. Native build uses the existing local
Alpine guest; no WSL/NixOS input or alternative browser emulator is used. Prefix
preparation is not a full kernel/compiler closure gate. Whole-image -104, boot,
PID 1, exception/device/root delivery and full development acceptance remain red.
