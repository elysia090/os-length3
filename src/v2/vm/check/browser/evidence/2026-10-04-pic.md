## State and ownership

The PC pair has separate request, mask, in-service, physical input and
priority coordinates. Let `rank_p(bits)` be the first set bit in the rotated
eight-position order, or 8 for empty. A request is eligible precisely when
`rank_p(IRR & ~IMR) < rank_p(blocking ISR)`. Special-mask mode removes masked
service bits; master fully-nested mode removes the slave-cascade bit from the
blocking set. Acknowledgment updates service/request and optional rotation;
edge input requires a rising edge, level input retains an asserted request.

The [8259-compatible datasheet](https://www.renesas.com/en/document/dst/82c59a-datasheet)
defines the request/service/mask registers and ICW/OCW protocol. C owns byte
ports 20/21, A0/A1 and PC ELCR 4D0/4D1, including initialization, poll, EOI,
masking, rotation, automatic EOI, edge/level and the fixed IR2 slave wiring.
8080 initialization is explicitly unsupported. C-model pending/acknowledgment
tests are not a CPU interrupt-delivery claim: device IRQ/event delivery to the
CPU, APIC and NMI remain incomplete. No host time is required for register I/O.

Generated cuts still call the existing `io` boundary. The shared C privilege /
TSS-bitmap check precedes any mutation; denied access faults before checking
device width. Byte register accesses complete synchronously, preserving CPU
ownership and not stealing a pending clock ticket. Wider device accesses,
unsupported initialization and stale generations refuse without device changes.
Close/reopen resets device state. No JS PIC, port switch, guest-opcode callback,
second interpreter, source skip or fabricated successful read was added.
