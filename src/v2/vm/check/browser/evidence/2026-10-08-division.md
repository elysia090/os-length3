# Common arithmetic, flag and memory closure — 2026-10-08

The native bundle and human UI are unchanged. These are completed family
implementation/execution gates, not browser Linux acceptance. No product
interpreter, source opcode skip, numeric VM callback or SoftFloat runtime is added.

## One arithmetic path

Integer memory, binary32/64 memory and register arithmetic share exact extended
significands, PC/RC rounding, NaN/unsupported/empty/denormal classification,
exception priorities, deferred publication and tags. Memory widening consumes
the existing IEEE SSA and preserves source denormal class. Reverse/pop are
operand/state projections. FOP uses decoded opcode/ModRM, not prefix bytes.

The EXISTING physical Windows observer now captures these additional families.
Code is RX, operands on a separate RW page, saved coordinates representable.
One bounded form buffer is retained. FPU/RFLAGS are physically observed; GPR
invariance is architectural, not every live host GPR being captured.

All **300,672** added rows pass cold C -> ordinary Wasm -> actual C MMU/table.
The old 42,624 register arithmetic rows remain green. Integer/memory controls
cover four PC/four RC/seven mask contexts. Register controls retain six masks:
separately unmasked register ZE is not yet included and is not inferred.

Official authenticated SoftFloat 3e matches 3,840 canonical masked integer
division cases, 14,898 register division cases, 7,449 register multiply cases,
and **480,000** canonical finite register samples across all six operations.
Noncanonical/empty/deferred publication and DE are outside that library's
reference domain; hardware records cover them. It is never product-linked.

Significand division retains only remainder zero/below-half/tied/above-half
as 0, 1, 2^63 and 2^63+1. This preserves every future right-jam/rounding
observation without materializing another 64 fraction bits. ZE suppresses
lower-priority DE. Unmasked IE/DE/ZE retain payload; OE/UE/PE use the existing
rounded/scaled publication. Multiply uses radix-2^32 limbs:
t=(a0*b0>>32)+a1*b0; u=a0*b1+(t mod 2^32);
hi=a1*b1+(t>>32)+(u>>32); lo=a*b mod 2^64.
Intermediate sums fit u64; normalize the pair and share the rounding consumer.

## Shared U128/U64 quotient

N=H*2^64+L fits one quotient word iff H<D, also proving D!=0. Invalid operands
publish zero payloads and a #DE predicate. Safe internal D=1,H=L=0 make the
graph engine-total. Normalize D, split radix-2^32, estimate two digits and
perform two guarded corrections per digit. Normalized leading digit >=2^31
bounds the overestimate by two. Modular multiply/subtract recovers bounded
remainders; shift zero is explicit, avoiding C shift-by-64.
This specializes Algorithm D, not a global-minimum theorem.
[LLVM's primary implementation/reference](https://raw.githubusercontent.com/llvm/llvm-project/main/compiler-rt/lib/builtins/udivmodti4.c)
identifies Knuth Volume 2 section 4.3.1 and the correction bound.

One unsigned-divide.c fragment: **82 abstract nodes/span46/22,688 arena bytes**,
not minimal x86 instruction costs. **1,003,264** independent real CPU
divq/fault-predicate controls pass. The old 64-round Wasm restoring body is
DELETED; H==0's fast path and signed magnitude/#DE boundaries remain.
Integer execution: 32 native/cold forms, 16,384 direct + 16,384 C comparisons,
10,348 #DE records, 160 refusals, 1,140 wide algebra controls.

## Flag and memory closure

LAHF observes the live flags into AH; SAHF substitutes five low flags; CMC
reads then complements CF. Shared backward flag liveness retains these reads.
168 prefix/composition forms / **43,008** complete native rows pass direct
and C execution plus byte parity; 672 unchanged-refusal controls pass.

RCL/RCR rotate (word,carry). Narrow pairs fit i64; 65-bit pairs substitute
two shifts plus carry. k=1's shift-by-64 cross term is explicitly zero.
Reduced count zero preserves flags; count1 defines OF; undefined multibit OF
selects zero. CL/CH aliases capture inputs before publication. Memory reuses
C reserve/commit, including zero-count write-permission faults.
Old tests asserting refusal now assert typed admission or unchanged capacity
failure; they do not mask a numeric mismatch.

Memory: 476 forms / **243,712 direct + 243,712 C** rows / **47,936 faults** /
9,436 zero-write faults / 1,904 waits+retries / 2,380 refusals /

## Reproduction

```sh
make -C src/v2/x86 unsigned-divide-check
make -C src/v2/wasm-compiler check
node data/oracle/check-x87-state.mjs VM.WASM COMPILER.WASM RECORDS --divide
# Repeat each observer/checker mode in the first table.

node data/oracle/check-wasm-dispatch.mjs VM.WASM ROTATE-RECORDS

```

Physical observer: existing x87-arithmetic-observe.c, each mode into a fresh
directory. SoftFloat checkers link arithmetic, unsigned-divide, ieee, value,
compact, sweep, arena, and pinned reference library with FAST_INT64/LITTLEENDIAN;
never product execution. Register checker: --divide --ssa, --multiply --ssa,
or --finite. Receipts under temp/x87-division-1008 are ignored test data,
not distribution payloads. inspect-wasm-closure.c prints unresolved product
grammar coordinates without modifying acceptance or executing instructions.
