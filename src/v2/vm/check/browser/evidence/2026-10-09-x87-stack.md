# Tag release and cyclic TOP in the common SSA path — 2026-10-09

FFREE, FFREEP, FINCSTP and FDECSTP consume one checked law and one two-output
pure SSA. The VM did not gain an x87 interpreter, opcode callback or floating
library. The existing EM/TS and pending #MF/FERR guard precedes the generated
state writes. Tags/TOP are small physical fields; no payload register, lane
array or CPU snapshot is copied to perform these operations.

## Exact field derivation

For status word S, tag word T, logical source i and step d:

```text
TOP = (S >> 11) & 7
tag_address = 2 * ((TOP + i) & 7)
            = ((S >> 10) + 2*i) & 14

FFREE:  T' = T | (3 << tag_address)
FFREEP: T' = T | (3 << tag_address) | (3 << ((S >> 10) & 14))

TOP step:
S' = (S & 0xc5ff) | ((S + (d << 11)) & 0x3800)
no TOP step:
S' = S & 0xfdff
```

The discarded low bit of `S >> 10` is C2; adding even 2*i cannot introduce a
carry from it. Masking after the addition gives the cyclic tag coordinate
directly. The status addition is masked before merging so TOP wrap cannot
change C3. C1 clears in all forms. FFREEP releases both its selected register
and the old top before advancing; FINCSTP/FDECSTP change TOP but never release
a tag. Source 0 shares its tag mask with the pop mask automatically.

The former sequential field extraction had a maximum 15 SSA nodes. Substitution
and exact packed-field normalization reduce the maximum to **work 12/span 6**.
This is an upper bound for this checked family, not a global x86 optimum or a
Linux speed measurement. Completed operations update FIP but preserve FOP/DP
and numeric payloads. Those fields were independently observed, not guessed
from the mnemonic.

The common DAG emitter now accepts an explicit output count, so two-field
transfers do not fabricate a third result. Existing three-output arithmetic
uses the same checked traversal. The declared engine-local bound accounts for
the four typed arguments/logical-slot mapping. Reducing that bound first
exposed an invalid local in FFREEP ST(1); actual engine validation caught it,
and all 144 final generated modules were rebuilt and executed after correction.
