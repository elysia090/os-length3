## Derivation: exact raw interchange, not rounded conversion

Let f be the fraction width (23/52), b the exponent bias (127/1023), e the raw
exponent and m the raw fraction. Extract sign independently. Extended fields
are exactly:

```text
normal:     sig = (2^f | m) << (63-f), exp = e + 16383-b
subnormal:  l = clz64(m), sig = m << l, exp = 16384-b-f+63-l
zero:       sig = 0, exp = 0, retain sign
inf/NaN:    sig = (2^f | m) << (63-f), exp = 32767
```

Zero is selected separately, so the lane's defined modulo shift does not
become a C shift by 64. The raw NaN projection retains signaling/quiet bit
and payload; consuming operations own quieting/exception behavior. Return
source denormal, source SNaN and source zero class bits too. Converting a
binary32/64 subnormal to a NORMAL extended value must not erase the source's
DE observation. PC/RC and f64 arithmetic play no part in this exact projection.
