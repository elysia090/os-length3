# Control fields without an artificial SSA entrance — 2026-10-09

FLDCW now consumes the exact two-byte operand through the existing C memory
boundary after old #NM / pending #MF or FERR checks. The shared pure plan
canonicalizes CW and recomputes ES/B from newly unmasked old status flags.
New pending exceptions are deferred to the next waiting instruction. No FPU
payload, FIP/FDP/FOP, tag or integer flag is rewritten by this control load.

The scalar emitter had unnecessarily accepted only five- or six-input plans.
It rejected this genuine two-input state transfer. The emitter now accepts the
common bounded 1..19 input frame; precise node/operand/projection checks are
unchanged. Exact-body tests cover every input count and untouched overflow.
This removes the general entrance restriction rather than padding the control
plan with unused fields or adding a separate emitter.

ES/B depends only on the six original mask bits. Substituting those before CW
canonicalization makes the two publication chains independent: same 9 graph
operations, span 8 -> 6. These are measured graph bounds, not global minima.
The test pins span <= 6 and exhausts all 65,536 raw words x 64 pending sets.

128 address/register/prefix constructors and 1,536 malformed laws pass.
8,192 independent physical Windows raw-word/full-FPU/tag/flag receipts match
compiled Wasm/C VM execution. 12,288 actual C MMU/table boundary models pass:
9,216 #NM, 512 #MF, 512 FERR waits, 512 source PF, 512 residency waits/retries
and 1,536 exact retirements. The source extent, read-only/cross-page/FS/GS/
address32 cases, old-exception precedence and no partial CPU publication are
pinned independently. Native reserved-word observations and exhaustive models
are different populations, not a claim of exhaustive physical sampling.
Scoped product/postlink and positive ASan/UBSan gates pass; the separate
intermittent near CALL RAM-payload red remains recorded.
